🚀 IMPLEMENTATION FOR OTHER PAGES:

Step 1: Create page file
  /pages/maps/atlas.js
  /pages/planning-tools/index.js
  /pages/current-affairs/index.js

Step 2: Import component
  import { SchemePageLayout } from '@/components/public/SchemePageLayout';

Step 3: Fetch your data
  collection(db, 'YOUR_COLLECTION')
  where('type', '==', 'YOUR_TYPE')

Step 4: Extract categories
  const categories = useMemo(() => {
    const s = new Set();
    items.forEach(item => {
      if (item.YOUR_CATEGORY_FIELD) s.add(item.YOUR_CATEGORY_FIELD);
    });
    return Array.from(s).sort();
  }, [items]);

Step 5: Define statistics
  const statistics = [
    { icon: Icon1, number: '120+', label: 'Items' },
    { icon: Icon2, number: '35+', label: 'Categories' },
    // ... more statistics
  ];

Step 6: Render component
  <SchemePageLayout
    title="Your Title"
    description="Your Description"
    heroImage="/images/your-hero.png"
    schemes={items}
    categories={categories}
    loading={loading}
    searchQuery={searchQuery}
    onSearch={setSearchQuery}
    statistics={statistics}
  />

📋 COMPONENT PROPS:

Required:
  ├── title: string                  - Page title
  ├── description: string            - Page description
  ├── schemes: array                 - Your data items
  ├── categories: array              - Filter options
  └── onSearch: function             - Search callback

Optional:
  ├── heroImage: string              - Hero image path
  ├── loading: boolean               - Show loading state
  ├── searchQuery: string            - Current search value
  └── statistics: array              - Stats cards (4 recommended)

═════════════════════════════════════════════════════════════════════════════════

📦 DATA STRUCTURE:

Each item in schemes array should have:
  {
    id: "unique-id",                 - Unique identifier
    title: "Item Title",             - Main title
    summary: "Description",          - Brief summary
    sector: "Category Name",         - Filter category
    ministry: "Ministry/Org",        - Organization name
    year: 2023,                      - Launch year
    image: "/path/to/image.jpg",     - Card image
    slug: "url-slug",                - URL slug for details page
    featured: false                  - Highlight if true
  }

📞 TROUBLESHOOTING:

Issue: No items showing
Fix: Check data structure matches required fields
     Check Firebase query is correct
     Check browser console for errors

Issue: Categories not appearing
Fix: Verify all items have the category field
     Check field name matches in code
     Verify values are consistent

Issue: Search not working
Fix: Check items have title, summary, ministry fields
     Check searchQuery is passed through onSearch callback
     Try typing slowly to see instant results

Issue: Images not showing
Fix: Verify image paths are correct in /public/images/
     Check image files actually exist
     Use full paths like /images/maps-hero.png
